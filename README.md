# MSNEmulator

Actually bridge from MSNP2 to Telegram

## How to make it work?

1. Go to `hosts` file and type in:
```txt
127.0.0.1 messenger.hotmail.com
```
2. Create Telegram bot via BotFather
3. Once you created it, grab the token and paste it into `config.ini`
4. Start the emulator
5. Start MSN Messenger 1.0-2.0083 (cuz this is the versions that supports MSNP2)
6. Now you have MSN Messenger as Telegram Client
